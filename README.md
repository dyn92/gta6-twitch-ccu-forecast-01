Forecast GTA VI's launch-day Twitch viewers hour by hour: a pure-stdlib Python forecaster that reads a launch case (hour-1 viewers, pre-release history, 38 comparable game launches) and writes calibrated 5-quantile forecasts for hours 2–24.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
